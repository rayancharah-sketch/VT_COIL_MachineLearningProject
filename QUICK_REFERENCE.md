## 🚀 Quick Commands

### First-Time Setup
```bash
# 1. Install all dependencies
pip install -r requirements.txt

# 2. Configure Kaggle API (one-time)
# Place kaggle.json in C:\Users\<YourUsername>\.kaggle\

# 3. Download dataset
python data.py

# 4. Train the model
python train_model.py

# 5. Launch web app
python app.py
```

### Or Use the Automated Setup Script
```bash
python run_project.py
```

## ⚠️ Troubleshooting

### Problem: Import errors
```bash
# Solution: Reinstall specific package
pip install tensorflow==2.15.0 --force-reinstall
```

### Problem: Kaggle API not working
```bash
# Solution: Check kaggle.json location
dir C:\Users\%USERNAME%\.kaggle\

# Should show: kaggle.json
```

### Problem: Model training takes too long
- Reduce `epochs` in train_model.py (try 20 instead of 50)
- Use a smaller batch_size (try 16 instead of 32)

### Problem: Web app shows "Model not found"
```bash
# Solution: Train the model first
python train_model.py
```

### Problem: Port 5000 already in use
```bash
# Solution: Kill the process or use different port
# Edit app.py line: app.run(..., port=5001)
```
