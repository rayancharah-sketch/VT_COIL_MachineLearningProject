About This Project

Project Overview

This diabetes risk prediction application uses machine learning to assess an individual's risk of developing diabetes based on various health metrics. The project was developed as part of the VGC Group Project for Virginia Tech and USFQ courses.

Learning Objectives

  • Understand how neural networks work and classify medical data
  • Gain practical experience with Python, TensorFlow/Keras, and scikit-learn
  • Explore the application of AI and machine learning in healthcare
  • Develop web applications that integrate machine learning models

Technology Stack

🧠 Machine Learning
  • TensorFlow/Keras - Neural Network Framework
  • scikit-learn - Data Preprocessing & Metrics
  • pandas - Data Manipulation
  • NumPy - Numerical Computing
🌐 Web Development
  • Flask - Web Framework
  • Bootstrap 5 - UI Components
  • HTML/CSS/JavaScript - Frontend

Model Architecture

The prediction model is a feedforward neural network with:

  • Input Layer: Accepts normalized health metrics
  • Hidden Layer 1: 16 neurons with ReLU activation and 30% dropout
  • Hidden Layer 2: 8 neurons with ReLU activation and 20% dropout
  • Output Layer: 1 neuron with sigmoid activation for binary classification

Dataset

The model is trained on the "Healthcare Diabetes" dataset from Kaggle (nanditapore/healthcare-diabetes), which contains various health indicators and diabetes outcomes for multiple individuals.

AI & LLM Usage

This project follows ethical AI guidelines set by Virginia Tech and USFQ. Large Language Models (LLMs) such as ChatGPT were consulted for:

  • Brainstorming model architectures and design patterns
  • Debugging code and explaining error messages
  • Generating ideas for visualization and explainability features

All AI-generated code was reviewed, tested, and modified by the team to ensure accuracy and appropriateness for this application.
